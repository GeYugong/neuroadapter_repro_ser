# E0 公开 ROI 映射

本目录中的生成产物采用公开的 Algonauts Project 2023 Subject 1
fsaverage ROI masks 作为主要实验协议。

使用 NSD 官方原生标签进行重采样的结果仍保留在历史目录
`experiments/roi_ablation/mapping/` 下，用作敏感性分析；功能 ROI
因果研究不以它作为主要映射。

## 结果

完整 1000-parcel 清单中，全部 97 个具有功能标签的 parcel 都已被
top-SNR-200 保留。V4、Face 和 Word 的选择率均为 1.0。因此，公开映射
没有提供 top-SNR-200 降低这些 ROI 覆盖率的证据。
